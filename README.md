# MAXIM Brand

맥심의 브랜드 감성과 커피가 만들어 내는 하루의 순간을 담은 반응형 브랜드 웹사이트입니다.

**배포 사이트:** [maxim-brand](https://hyeon924.github.io/maxim-brand/)

## 소개

"커피를 마시는 일은 나를 돌보는 일"이라는 메시지를 중심으로, 아침부터 저녁까지의 커피 리듬을 감각적인 화면 전환과 함께 소개합니다. 브랜드의 주요 발자취를 확인할 수 있는 히스토리 페이지도 제공합니다.

## 주요 화면

- 홈: 커피와 함께하는 네 가지 일상 순간 및 브랜드 메시지
- 맥심 히스토리: 1980년부터 이어지는 제품 출시와 주요 연혁 타임라인
- 반응형 내비게이션: 데스크톱 및 모바일 환경을 고려한 메뉴 UI
- 맨 위로 이동: 스크롤 위치에 따라 표시되는 빠른 이동 버튼

## 기술 구성

- React
- TypeScript
- Vite
- CSS
- Lucide React

## 프로젝트 구조

```text
src/
├── components/   # 공통 헤더·푸터
├── pages/        # 홈 및 히스토리 화면
├── lib/          # 에셋 경로 유틸리티
├── App.tsx       # 페이지 전환 및 공통 UI
└── styles.css    # 전체 스타일
public/assets/    # 이미지·영상 에셋
```

## 배포

GitHub Pages를 통해 배포하며, `main` 브랜치에 변경 사항이 반영되면 GitHub Actions 워크플로가 빌드와 배포를 진행합니다.

## 참고

이 프로젝트는 맥심 브랜드를 주제로 제작한 포트폴리오용 웹사이트입니다. 상표와 관련 콘텐츠의 권리는 각 권리자에게 있습니다.
