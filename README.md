# 맥심 브랜드 웹사이트

기존 맥심 브랜드 퍼블리싱 자료를 React 기반으로 마이그레이션하고, 브랜드 스토리텔링을 풀페이지 스크롤 경험으로 재구성한 개인 프론트엔드 프로젝트입니다.

배포 사이트: https://hyeon924.github.io/maxim-brand/

> 본 프로젝트는 개인 포트폴리오 및 학습 목적으로 제작한 리팩토링 작업물입니다. MAXIM 및 관련 브랜드가 운영하는 공식 웹사이트가 아니며, 원본 콘텐츠·이미지의 권리는 각 권리자에게 있습니다.

## 소개

기존 정적 HTML/CSS/jQuery 기반 화면을 React, TypeScript, Vite로 전환했습니다. 기존 정보 구조를 유지하되, 이미지 의존도를 낮춘 에디토리얼 스타일의 UI와 CSS Scroll Snap 기반 풀페이지 인터랙션을 적용했습니다.

메인 화면은 “커피를 마시는 순간”이라는 브랜드 메시지를 중심으로 구성했으며, 반응형 내비게이션과 모바일 환경에 맞춘 일반 스크롤 레이아웃을 구현했습니다.

## 주요 화면

- 홈: 커피와 일상의 리듬을 주제로 한 브랜드 메시지 풀페이지 구성
- 커피 모먼트: 아침·휴식·집중·저녁의 장면을 표현한 인터랙티브 카드
- 브랜드 스토리: 작은 커피 습관과 브랜드 이야기를 연결하는 에디토리얼 섹션
- 브랜드 연혁: 1980년부터 이어진 맥심의 주요 기록을 타임라인으로 구성
- 반응형 내비게이션: 데스크톱 드롭다운 메뉴와 모바일 확장 메뉴 UI
- 인터랙션: 풀페이지 스크롤 스냅, 카드 호버 효과, 맨 위로 이동 버튼, 부드러운 페이지 전환

## 기술 구성

- React
- TypeScript
- Vite
- CSS
- Lucide React
- GitHub Actions / GitHub Pages

## 프로젝트 구조

```text
src/
├── components/   # 공통 헤더·푸터 컴포넌트
├── lib/          # GitHub Pages 자산 경로 유틸리티
├── pages/        # 메인 및 브랜드 연혁 페이지
├── App.tsx       # 경로 전환 및 공통 레이아웃 조합
├── main.tsx      # React 진입점
└── styles.css    # 전역 스타일 및 반응형 UI
public/
└── assets/
    └── img/      # 기존 이미지·영상 자산
legacy/           # 보존된 기존 HTML/CSS/jQuery 퍼블리싱 원본
.github/
└── workflows/
    └── deploy-pages.yml  # GitHub Pages 자동 배포 워크플로
```

## 배포

GitHub Pages를 통해 배포합니다. `main` 브랜치에 변경 사항이 반영되면 GitHub Actions 워크플로가 프로덕션 빌드와 배포를 진행합니다.
